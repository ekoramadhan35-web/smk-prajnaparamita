Integrasi Google Apps Script (GAS)

Hubungkan website Kepala Sekolah ini ke Google Sheets spreadsheet Anda untuk penyimpanan data otomatis.

Kode Script Google Sheets (Code.gs) 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (data.action === 'addGuru') {
    sheet.appendRow([new Date(), data.nama, data.website, data.kompetensi, data.filosofi]);
    return ContentService.createTextOutput(JSON.stringify({result: 'success'})).setMimeType(ContentService.MimeType.JSON);
  }
}
function doGet(e) {
  return ContentService.createTextOutput("GAS Active");
}
